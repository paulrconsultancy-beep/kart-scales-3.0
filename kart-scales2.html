Kart Scales

One Chrome setting is needed The pads broadcast their weight, and Chrome only lets pages hear broadcasts with this switched on:
  1. In Chrome’s address bar, type chrome://flags/#enable-experimental-web-platform-features
  2. Set Experimental Web Platform features to Enabled
  3. Tap Relaunch, then come back to this page

Connect both pads to weigh.
Calibration and smoothing

Do this once per pad. With the pad empty, tap Set zero. Then place a weight you know exactly (e.g. 20.0 kg of plates) in the middle of that pad, enter it and tap Calibrate. Settings are saved on this phone.

Pad data

Each pad broadcasts 20 bytes. Bytes that have changed since connecting are underlined, and the bytes being read as weight are outlined. Leave this on “Weight value” unless the reading doesn’t follow the load.
